# Customer Management System

PHP ve MySQL kullanılarak geliştirilmiş müşteri yönetim sistemi.

## Technologies

- PHP
- MySQL
- PDO
- HTML
- CSS

## Features

- Admin registration and login system
- Session management
- Password hashing
- Customer CRUD operations
- Customer add, update, delete and listing operations

## Project Structure

- `login.php` → Admin giriş işlemleri
- `register.php` → Admin kayıt işlemleri
- `dashboard.php` → Ana panel
- `customers/` → Müşteri CRUD işlemleri
- `database.php` → Veritabanı bağlantısı

## Installation

1. XAMPP Apache ve MySQL servislerini başlatın.
2. Projeyi htdocs klasörüne taşıyın.
3. Veritabanını phpMyAdmin üzerinden içe aktarın.
4. Tarayıcıdan projeyi çalıştırın.
